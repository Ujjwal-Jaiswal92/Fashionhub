# 👕 FashionHub

A web-based **e-commerce clothing platform** developed as a semester project. FashionHub provides customers with a smooth online shopping experience while offering administrators an efficient system to manage products, categories, users, and orders.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Ujjwal-Jaiswal92/Fashionhub.git
```

### Navigate to the project

```bash
cd FashionHub
```

### Start XAMPP

- Start **Apache**
- Start **MySQL**

### Configure the database

1. Open **phpMyAdmin**
2. Create a database named:

```text
fashionhub
```

3. Import:

```text
database/fashionhub.sql
```

### Run the project

Move the project folder into:

```text
xampp/htdocs/
```

Open:

```text
http://localhost/FashionHub/
```
